# 작은 사무실 (work_meta)

담당자에게 업무를 지시하고 보고를 받으며, 서랍에 문서를 보관하는 3D 사무실입니다.
원본 메타버스 전시관의 구조만 참고했고 코드와 에셋은 새로 작성했습니다. 분석 기록은 [docs/rea-analysis.md](docs/rea-analysis.md)에 있습니다.

## 할 수 있는 일

- **공간**: 벽돌 벽과 카펫의 메인 사무실에 5명(총괄·조사·분석·마케팅·기타)이 근무하고, 맨 위에 내 자리가 있습니다. 오른쪽 통로를 지나면 미팅룸입니다.
- **이동과 화면**: 바닥 클릭, WASD로 이동. 끌어서 둘러보기, 휠·핀치·`+`/`-` 버튼으로 확대·축소, `내 근처로` 버튼으로 내 주변을 크게 봅니다. 화면은 공간 경계 밖을 보여 주지 않습니다.
- **화면 배치**: 메뉴, 화면 도구, 대화창은 손잡이(⠿)를 끌어 옮기고, 두 번 누르면 원래 자리로 돌아갑니다. 메뉴는 ☰로 접습니다. 배치는 이 브라우저에 저장됩니다.
- **대화와 지시**: 담당자 가까이 가서 대화창에 말하거나, 담당자를 눌러 지시합니다. 혼자 있을 때 말하면 총괄이 키워드로 담당자에게 나눕니다. 결과는 `결과 보고서` 서랍에 자동 보관됩니다.
- **협업**: 지시에 `@담당자`를 쓰면 그 담당자가 먼저 일하고 결과를 넘깁니다. 담당자들은 실제로 동료 자리로 걸어가 전달합니다.
- **회의**: 회의 소집을 누르면 전원이 미팅룸에 모입니다. 패널을 닫으면 자리로 돌아갑니다.
- **서류장**: 서랍에 파일과 링크를 보관하고, 웹페이지·PDF·HTML·이미지·텍스트를 앱 안에서 엽니다. 서랍마다 구글 드라이브 폴더를 연결할 수 있습니다.
- **앱 연결 문**: 미팅룸 북쪽 벽의 문 3개입니다. 첫 문은 AI4Insurance로 연결되어 있고, 나머지는 문 설정에서 주소를 넣으면 됩니다.

## 공간 추가

`src/world.js`의 `ROOMS`에 한 줄을 더하면 동쪽으로 공간이 이어지고 바닥·벽·통로·길찾기·안내판이 따라옵니다. 가구는 `buildOffice`에 놓습니다.
앱 문은 `DOOR_SPOTS`에 공간과 x 위치로 추가합니다. 사무실 벽에도 둘 수 있고, 순서가 저장된 연결과 맞물리므로 뒤에만 추가합니다.

## 담당자 유형

| 유형 | 실행 위치 | 필요한 설정 |
|------|-----------|-------------|
| 채팅 봇 (Claude) | 서버 | `ANTHROPIC_API_KEY` |
| 내장 분석 앱 | 브라우저 | 없음 (CSV·TSV 통계, 텍스트 요약 수치) |
| 내장 문서 검색 | 브라우저 | 없음 |
| 외부 앱 (웹훅) | 서버 | `WEBHOOK_ALLOWED_HOSTS`에 호스트 등록 |
| 사람 담당자 | 없음 | 업무 보드에서 직접 보고 |

### 외부 앱 연결 규약

서버가 HTTPS로 `POST {"agent":"이름","input":"지시 내용"}`을 보냅니다. 앱은 `{"result":"결과"}` 또는 일반 텍스트로 응답하면 됩니다. n8n, Zapier, 직접 만든 API 모두 연결할 수 있습니다.

## 실행과 배포

```bash
npm install
npm test
npx vercel dev   # /api/agent까지 함께 실행
```

Vercel 환경 변수는 `.env.example`을 참고하세요. `OFFICE_ACCESS_KEY`가 없으면 서버 API는 닫혀 있습니다. 앱의 설정 메뉴에 같은 키를 입력해야 봇을 쓸 수 있습니다.

## 알려 둘 제한

- 업무와 문서는 브라우저 IndexedDB에 저장됩니다. 기기 간 공유, 다중 사용자, 실시간 접속 표시는 없습니다.
- 외부 사이트가 임베드를 막으면 뷰어가 비어 보입니다. 이때는 `새 탭에서 열기`를 쓰세요.
- PDF, 이미지 등 이진 파일은 내용을 봇에게 넘기지 않습니다. 텍스트 계열 파일만 첨부로 전달됩니다.
- Claude 응답은 Vercel 함수 60초 제한에 맞춰 `effort: low`로 호출합니다.
